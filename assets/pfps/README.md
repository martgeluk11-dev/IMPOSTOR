# Player profile pictures

Place the 8 profile-picture files in this folder using these filenames:

- `pfp-01.webp`
- `pfp-02.webp`
- `pfp-03.webp`
- `pfp-04.webp`
- `pfp-05.webp`
- `pfp-06.webp`
- `pfp-07.webp`
- `pfp-08.webp`

Use WebP for the images when possible. If an image is actually PNG or JPEG, keep its real extension (`.png` or `.jpg`) unless you convert it first. Recommended image shape: square (1:1).
